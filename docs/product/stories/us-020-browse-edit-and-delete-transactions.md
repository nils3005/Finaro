# US-020 — Browse, edit, and delete transactions

Epic: [EP-04 — Transactions](../epics/ep-04-transactions.md)

**As** a user, **I want** to find, correct, and delete my transactions, **so that** my data stays accurate.

## Acceptance criteria

- [ ] The transaction list can be filtered (period, category, type) and sorted
- [ ] The list is paginated
- [ ] Users can edit and delete transactions; deletion asks for confirmation
- [ ] Category corrections are recorded

## Tasks

- [ ] List endpoint with filter, sort, pagination
- [ ] Update / delete endpoints
- [ ] List UI with edit / delete
- [ ] Tests
