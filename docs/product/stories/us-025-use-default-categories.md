# US-025 — Use default categories

Epic: [EP-05 — Categories](../epics/ep-05-categories.md)

**As** a new user, **I want** a sensible set of categories from the start, **so that** I can begin logging immediately.

## Acceptance criteria

- [ ] A default set exists (e.g. food, transport, leisure, rent, education, income)
- [ ] Category names are translated (`en`, `de`)
- [ ] Categories are used by analytics, budgets, and recommendations
