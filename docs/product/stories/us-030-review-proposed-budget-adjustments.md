# US-030 — Review proposed budget adjustments

Epic: [EP-06 — Budgets](../epics/ep-06-budgets.md)

**As** a user, **I want** proposed budget adjustments based on my spending, **so that** my plan adapts to reality.

## Acceptance criteria

- [ ] After overspending, the system proposes an adjustment (e.g. smaller leisure budget next week)
- [ ] Each proposal explains the data it is based on
- [ ] The user accepts or rejects; nothing changes without confirmation
