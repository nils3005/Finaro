# US-033 — See my financial overview on the dashboard

Epic: [EP-08 — Analytics & reports](../epics/ep-08-analytics-reports.md)

## Acceptance criteria

- [ ] Summary cards for income, expenses, savings
- [ ] Category breakdown and trend chart over time
- [ ] Charts are visually distinct from standard banking apps and work in both themes
