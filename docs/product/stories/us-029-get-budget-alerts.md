# US-029 — Get budget alerts

Epic: [EP-06 — Budgets](../epics/ep-06-budgets.md)

**As** a user, **I want** to be alerted when I approach or exceed a budget, **so that** I can react in time.

## Acceptance criteria

- [ ] An alert is created at > 80 % and > 100 % of a budget
- [ ] Each threshold alerts only once per period
