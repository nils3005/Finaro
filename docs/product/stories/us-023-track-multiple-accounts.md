# US-023 — Track multiple accounts

Epic: [EP-04 — Transactions](../epics/ep-04-transactions.md)

**As** a user, **I want** to track several accounts in one overview, **so that** I see my whole financial picture.

## Acceptance criteria

- [ ] Users can create accounts (e.g. several checking accounts)
- [ ] Every transaction belongs to an account
- [ ] Overviews can show all accounts or filter by account
- [ ] Transfers between own accounts are not counted as income or expense

## Tasks

- [ ] Account model
- [ ] Migration for existing transactions
- [ ] Account filter in UI
- [ ] Transfer handling
