# US-027 — Rate categories by necessity

Epic: [EP-05 — Categories](../epics/ep-05-categories.md)

**As** a user, **I want** to rate categories as essential, worthwhile, or discretionary, **so that** analysis and advice respect what is important to me.

## Acceptance criteria

- [ ] Each category can be rated `essential` / `worthwhile` / `discretionary`
- [ ] Analytics show spending by rating
- [ ] AI recommendations do not flag worthwhile spending (e.g. textbooks) as savings potential

## Tasks

- [ ] Rating attribute
- [ ] Rating UI
- [ ] Use in analytics
- [ ] Use in insight prompts
