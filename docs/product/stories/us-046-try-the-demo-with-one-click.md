# US-046 — Try the demo with one click

Epic: [EP-12 — Landing page & demo](../epics/ep-12-landing-page-demo.md)

**As** a visitor (e.g. a recruiter), **I want** to try Finaro with one click, **so that** I see a populated product within seconds.

## Acceptance criteria

- [ ] One click creates a temporary, isolated demo account with several months of realistic data
- [ ] Demo accounts have all Pro features
- [ ] Demo accounts and their data are deleted automatically after a fixed lifetime
- [ ] Demo creation is rate-limited

## Tasks

- [ ] Demo provisioning endpoint
- [ ] Scheduled cleanup
- [ ] Rate limiting
- [ ] Demo entry on landing page
